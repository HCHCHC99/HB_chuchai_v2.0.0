# 实时数据使用说明

> 本文档已按当前代码（2026-08-05）更新；原文档的故障位定义（FAULT_BIT_OVERCURRENT / FAULT_BIT_OVERTEMP）与当前代码不符，已修正。原文件为 GBK 编码，现统一转为 UTF-8。

## 概述

实时数据（`AppRealTimeData_t`）用于存储设备运行时的动态数据，**不保存到 Flash**，仅运行时存在内存中。Modbus 读取保持寄存器时通过 `Param_ReadByReg()` 返回这些数据。

## 实时数据寄存器映射

| 寄存器地址 | 参数名 | 类型 | 单位 | 说明 |
|-----------|--------|------|------|------|
| 0x2730 | real_speed | int16_t | r/min | 实时转速 |
| 0x2731 | real_angle | int16_t | 0.1° | 实时角度（dev_rturn Pulse-Direct） |
| 0x2732 | real_voltage | uint16_t | 0.1V | 母线电压 |
| 0x2733 | real_current | uint16_t | 1mA | 电流 |
| 0x2737 | real_direction | int16_t | - | 实时转向 |
| 0x2740 | fault_status | uint16_t | - | 故障状态（位标志；写 0x2740 可清除故障） |

## 故障状态位定义（当前代码）

| 位 | 宏定义 | 说明 |
|---|--------|------|
| bit0 | FAULT_BIT_OVERVOLTAGE | 过压 |
| bit1 | FAULT_BIT_OVERCURRENT_FWD | 正转(开窗)过流 |
| bit2 | FAULT_BIT_OVERCURRENT_REV | 反转(关窗)过流 |
| bit3 | FAULT_BIT_RESET | 复位 |
| bit4 | FAULT_BIT_OVERLOAD | 过载 |
| bit5 | FAULT_BIT_STALL | 堵转 |
| bit6 | FAULT_BIT_UNDERVOLTAGE | 欠压（触发时自动保存绝对角度到 Flash 扇区 55） |

> 早期文档中的 `FAULT_BIT_OVERCURRENT`（bit1 单一位）与 `FAULT_BIT_OVERTEMP`（bit2）已废弃：
> 过流拆分为正转/反转向两个独立位（bit1/bit2），并新增 bit6 欠压。

## 实时数据来源（当前代码）

`App_Params.h` 中 `APP_PARAMS_USE_DEV_RTURN` 已定义（默认开启）：

```
Modbus_Poll() → Modbus_UpdateRealtime() → RealTime_UpdateFromDevice(
    ID_RTURN,          // 角度（CMD_RTURN_GET_ANGLE）
    ID_VOLTAGE_BUS,    // 母线电压
    ID_SENSOR_CURRENT) // 电流
```

- 转速/方向：dev_motor_hall（霍尔中断 + 1ms 更新）
- 角度：dev_rturn（Pulse-Direct：`fMinAngle + g_s32HallPulseAccum × 360/12/减速比`）

若注释掉 `APP_PARAMS_USE_DEV_RTURN`，则使用模拟实时数据 `g_SimRealtimeData`（Keil Watch 可修改，主循环 `SimRealtime_Sync()` 同步到真实数据）。

## 接口

### RealTime_Update()（选择性更新）

```c
#include "App_Params.h"

int16_t speed = 1500;
RealTime_Update(&speed, NULL, NULL, NULL, NULL);   // 只更新转速，其余保持不变

uint16_t volt = 320;  // 32.0V
uint16_t curr = 1500; // 1.5A
RealTime_Update(NULL, NULL, &volt, &curr, NULL);
```

参数顺序：`(speed, angle, voltage, current, direction)`，传 NULL 表示不更新。

### RealTime_UpdateFromDevice()

从设备管理器读取 dev_rturn / dev_voltage / dev_sensor 并刷新实时数据（Modbus 轮询使用）。

### 故障位操作

```c
RealTime_SetFault(FAULT_BIT_OVERCURRENT_FWD | FAULT_BIT_OVERCURRENT_REV); // 置位
RealTime_ClearFault(FAULT_BIT_OVERVOLTAGE);                                // 清除
bool f = RealTime_CheckFault(FAULT_BIT_STALL);                             // 检查
```

> `RealTime_SetFault` / `RealTime_ClearFault` / `RealTime_CheckFault` 是定义在 `App_Params.c` 中的普通函数（非内联函数）。

## 故障清除（写 0x2740）

Modbus 写 `REG_FAULT_STATUS (0x2740)` 会经 `Param_WriteByReg()` 分发：

- 写 `FAULT_BIT_OVERCURRENT_FWD` 或 `FAULT_BIT_OVERCURRENT_REV` → `FaultHandler_ClearFault(FAULT_TYPE_OVERCURRENT)`
- 写 `FAULT_BIT_OVERVOLTAGE` → 清除过压；写 `FAULT_BIT_UNDERVOLTAGE` → 清除欠压
- 写 `0x0000` → 清除全部故障

## 注意事项

1. 实时数据**不保存到 Flash**，掉电丢失（绝对角度除外，见 `关窗基准点.md`）
2. 从 Modbus 角度，实时数据寄存器只读；`0x2740` 例外，写它用于清除故障
3. 故障位可同时置多个，用 `|` 组合宏定义即可
