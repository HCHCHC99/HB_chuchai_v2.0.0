# 绝对角度功能说明

## 一、设计背景

现有实时角度（0x2731）依赖关窗过流校准，校准前角度无效，且掉电丢失零点。绝对角度功能在此基础上新增：

- **独立于校准**：无论是否完成关窗过流校准，绝对角度都能正常追踪
- **掉电不丢零点**：用户设定的绝对零点通过 Flash 持久化，上电自动恢复
- **欠压自动保存**：检测到欠压时自动将当前位置保存到 Flash，掉电后上电恢复
- **全部操作仅需单条 Modbus 指令**

---

## 二、数据模型

### 核心公式

```
绝对角度偏移 = RAM实时偏移 = 相对绝对零点的角度差 (单位 0.1°)

每 1ms 更新一次:
  delta = g_s32HallPulseAccum(当前) - s_last_accum(上次)
  s_abs_offset_x10 += delta × 3600 / (极对数 × 霍尔数 × 2 × 减速比)
```

### 关键变量

| 变量 | 存储位置 | 说明 |
|------|---------|------|
| `s_abs_offset_x10` | RAM | 实时偏移，每 1ms 更新，不掉电保留 |
| `s_last_accum` | RAM | `g_s32HallPulseAccum` 的上次快照 |
| `g_AbsAngle.abs_offset_x10` | Flash（扇区55） | 已保存的偏移值，掉电不丢 |
| `g_AbsAngle.goto_zero_thresh_x10` | Flash（扇区55） | 回零阈值 (0.1°)，默认1，范围0~200 |

### 方向约定

```
开窗(正转/FWD) → g_s32HallPulseAccum 增加 → 偏移增大 (正值方向)
关窗(反转/REV) → g_s32HallPulseAccum 减少 → 偏移减小 (负值方向)

偏移 > 0: 当前位置在绝对零点正方向（开窗超出的角度）
偏移 < 0: 当前位置在绝对零点负方向（关窗超出的角度）
```

## 三、程序架构

### 文件结构

| 文件 | 职责 |
|------|------|
| `Utils/App_RunAngle.h` | 接口声明、结构体定义、宏 |
| `Utils/App_RunAngle.c` | 核心逻辑：初始化、更新、设零、保存、回零 |
| `Utils/App_Params.h/c` | 寄存器读写 (Param_ReadByReg) |
| `App/App_Modbus.c` | 写路径拦截 (0x371A/0x371B → RunAngle_Cmd/RunAngle_SetThreshold) |
| `App/App_Motor_Project.c` | 初始化调用 + 主循环调用 RunAngle_Update() |
| `App/App_FaultHandler.c` | 欠压检测时自动触发保存 (RunAngle_Cmd(SAVE)) |

### 程序流程

```
上电启动:
  main()
    → Hardware_Init()
    → ...
    → ESystem_Init()
      → Param_Init(&g_AppParam)   // 加载常规参数
      → ... 设备初始化 ...
      → RunAngle_Init()           // 从 Flash 加载 abs_offset_x10 → RAM
                                  // 快照 g_s32HallPulseAccum → s_last_accum

主循环 (每 1ms):
  while(1)
    → ESystem_MainLoop()
      → ProcessDeviceUpdates()    // MotorHall update → g_s32HallPulseAccum 更新
      → RunAngle_Update()         // delta → s_abs_offset_x10 更新
                                  // 回零检测 (如果激活)
      → ...

欠压保存 (EventBus 回调):
  dev_voltage 检测到欠压
    → EventBus_Publish(TOPIC_VOLTAGE_ALARM)
    → App_FaultHandler::FaultHandler_OnVoltageAlarm()
        → RealTime_SetFault(bit6)
        → RunAngle_Cmd(ABS_CMD_SAVE)  ← 自动保存到 Flash
```

### 存储架构

```
Flash 扇区 55 (独立于常规参数扇区 62-56):
  使用 param_manager 多实例引擎
  结构体 AbsAngleRecord_t (32字节/条)
  魔数: 0xAB5AAB5A / 0xBA5ABA5A (独立, 防串扰)
  顺序追加写入 + CRC32 校验 + 磨损均衡
```

## 四、Modbus 寄存器

| 寄存器 | 地址 | 读写 | 数据类型 | 说明 |
|--------|------|------|----------|------|
| RAM偏移_LO | 0x3716 | R | int32 低16位 | 实时绝对角度偏移 (0.1°) |
| RAM偏移_HI | 0x3717 | R | int32 高16位 | |
| Flash偏移_LO | 0x3718 | R | int32 低16位 | Flash 中已保存的偏移 (0.1°) |
| Flash偏移_HI | 0x3719 | R | int32 高16位 | |
| 绝对角度指令 | 0x371A | W | uint16 | 命令寄存器 (见下表) |
| 回零阈值 | 0x371B | R/W | uint16 | 回零停止阈值 (0.1°)，默认 1，范围 0~200 |

### 0x371A 指令表

| 写入值 | 操作 | 说明 |
|--------|------|------|
| `00 00` | 设当前位置为绝对零点 | RAM=0, Flash=0, 写入Flash |
| `00 01` | 保存 RAM 偏移到 Flash | 固化当前偏移, 掉电后上电恢复 |
| `00 02` | 回到绝对零点 | 自动识别方向, 转动到阈值内后 ESTOP |

### 0x371B 回零阈值

| 操作 | 指令 | 说明 |
|------|------|------|
| 读 | `01 03 37 1B 00 01` | 返回 uint16 (0.1°) |
| 写 | `01 06 37 1B 00 0A` | 设 1.0° (值=10), 限幅 0~200, 写Flash, 热重载立即生效 |

## 五、操作指南

### 首次使用 (安装后)

```
1. 电机转到想要的"绝对零点"位置
2. 发: 01 06 37 1A 00 00    → 设零点
   此时 0x3716/0x3717 读回 0x00000000
```

### 正常运行中读取角度

```
读 RAM 实时偏移:
  发: 01 03 37 16 00 02
  回: 01 03 04 XX XX XX XX crc_l crc_h
  解析: 4字节拼为 int32, ÷10 = 度数 (正=开窗方向, 负=关窗方向)

读 Flash 已保存偏移:
  发: 01 03 37 18 00 02
  解析同上
```

### 保存到 Flash

**手动保存:**

```
发: 01 06 37 1A 00 01    → 保存到 Flash
下次上电后自动恢复
```

**自动保存 (欠压触发):**

当系统检测到欠压时，`App_FaultHandler` 会自动调用保存逻辑，将当前 RAM 偏移值写入 Flash。用户无需手动操作。上电后自动恢复掉电前的位置。

### 回零

```
1. 可选: 设置回零阈值  01 06 37 1B 00 0A  → 设 1.0°
2. 发: 01 06 37 1A 00 02                  → 自动转动到零点
   电机自动识别方向 → 转动 → 到达后 ESTOP 停止
```

### 回零阈值管理

```
读当前阈值: 01 03 37 1B 00 01  → 返回 uint16 (0.1°)
设阈值:     01 06 37 1B xx xx  → 写入 0~200, 热重载立即生效
```

## 六、回零逻辑详解

```
发 0x371A=2:
  偏移 > +阈值 → 发 REV (关窗方向) 指令
  偏移 < -阈值 → 发 FWD (开窗方向) 指令
  偏移在 ±阈值 内 → 无需转动, 直接结束

每 1ms (RunAngle_Update):
  检查偏移:
    |偏移| ≤ 阈值(0x371B) → 发 ESTOP, 结束
    偏移符号翻转 (越过零点) → 发 ESTOP, 结束
```

### 回零阈值

- 可通过 0x371B 寄存器配置，默认 1 (0.1°)
- 范围 0~200 (0° ~ 20.0°)
- 写入后立即生效 (热重载)，无需复位

### 回零中断

回零过程中可随时通过 Modbus 发 ESTOP (0x2720 bit2=1) 或过流保护中断转动。

### 回零后继续使用

回零完成后发 ESTOP 停转，用户可正常发送 FWD/REV 指令继续操作。

## 八、与实时角度 (0x2731) 的区别

| 维度 | 实时角度 (0x2731) | 绝对角度 (0x3716) |
|------|------------------|-------------------|
| 零点来源 | 关窗过流校准 | 用户手动设定 |
| 校准前有效 | 否 (返回0) | 是 |
| 掉电保留 | 否 | 是 (Flash + 欠压自动保存) |
| 更新频率 | 1ms (校准后) | 1ms (始终) |
| 数据类型 | int16 (0.1°) | int32 (0.1°) |
| 用途 | 限位、过流判断 | 位置记忆、回零 |

两者独立运行，互不影响。绝对角度的脉冲追踪与 dev_rturn 校准状态无关。
