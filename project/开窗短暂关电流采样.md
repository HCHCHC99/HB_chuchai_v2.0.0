# 反转消隐（开窗短暂关电流采样）

## 背景

电机从正转/停止切换到反转时，启动瞬间会产生较大的浪涌电流尖峰。此时 `dev_sensor` 的过流检测如果正常工作，很容易将启动浪涌误判为过流，导致 `Motor_OnCurrentAlarm` 或 `Motor_OnOvercurrentFwd` 被触发，向仲裁器插入 `block_fwd` 阻塞指令，从而错误地锁住电机。

**物理过程**：反转启动 → H 桥换相 → 短时大电流 → 50ms 内恢复至正常电流。这 50ms 就是需要"消隐"的窗口。

## 设计思路

### 核心思想

在仲裁系统**刚切换到反转**时，关闭 `dev_sensor` 的过流检测 50ms，给电机启动浪涌一个"消隐窗口"。50ms 后自动恢复过流检测。

### 为什么只对反转做消隐

反转（在应用中对应关窗动作）的启动浪涌尤为明显，且关窗到位后正常堵转也会产生大电流——这是预期行为，不能算故障。正转的工况不同，不需要此消隐。

### 为什么不是每次调用都重置定时器

仲裁系统选中反转后，`Motor_OnArbitrationRev()` 约每 10ms 被重复调用一次。如果每次调用都重置 50ms 定时器，消隐就永远不会结束。因此引入 `s_u8LastArbWasRev` 记录"上一次仲裁结果是否已经是反转"，**只在首次进入反转时**启动 50ms 定时器。

## 完整调用链

### 写入侧 — dev_motor

```
主循环 → DeviceManager 调度
    │
    ├─ Motor_Update()                              [每次主循环调用]
    │   ├─ 消隐定时器到期检查:
    │   │   if (标志==1 && nbDelay_IsComplete()) → 标志=0
    │   │
    │   └─ 每50ms仲裁一次:
    │       └─ Motor_ArbitrationDecision()
    │           └─ Motor_OnArbitrationRev()
    │               ├─ 首次进入? → 启动50ms定时器 + 标志=1
    │               └─ s_u8LastArbWasRev = 1
    │
    ├─ Motor_OnArbitrationFwd()
    │   └─ s_u8LastArbWasRev = 0, 标志 = 0       [离开反转立即取消]
    │
    └─ Motor_OnArbitrationStop()
        └─ s_u8LastArbWasRev = 0, 标志 = 0       [离开反转立即取消]
```

### 读取侧 — dev_sensor

```
主循环 → DeviceManager 调度
    │
    └─ Sensor_Device_Update()                      [每次主循环调用]
        ├─ Sensor_ReadFromAdc()                    [正常执行，不受影响]
        ├─ Sensor_CalcCurrent()                    [正常执行，不受影响]
        └─ Sensor_CheckOvercurrent()
            ├─ 检查 g_u8MotorReverseBlankActive?
            │   YES → return                       [消隐: 跳过过流检测]
            │   NO  → 正常执行过流判断逻辑
```

**关键**：消隐期间 ADC 读取和电流计算照常进行，Modbus 上报的电流值不受影响，只有过流报警判断被跳过。

### 时序示意

```
时间轴 →

[正转/停止] ──仲裁切换为反转──▶ [反转消隐 50ms] ──定时器到期──▶ [反转运行 + 过流检测正常]
                                      │                                    │
                              过流检测跳过                          如果关窗到位堵转过流
                              ADC读取和电流计算照常                  正常触发报警 + 阻塞
```

## 代码实现

### 涉及文件

| 文件 | 改动 |
|------|------|
| `dev_motor.h` | 定义消隐时长宏 `MOTOR_REVERSE_BLANK_MS` (50U)，声明全局标志位 |
| `dev_motor.c` | 管理消隐状态机：启动定时器、轮询到期、离开反转清除 |
| `dev_sensor.c` | 在 `Sensor_CheckOvercurrent` 入口检查消隐标志，消隐期间直接 return |

跨模块通信方式：`dev_motor.c` 定义全局变量 `g_u8MotorReverseBlankActive`，`dev_sensor.c` 内通过函数级 `extern` 声明引用，由链接器解析。

### dev_motor.h — 宏定义与外部声明

```c
// ========== 反转消隐配置 ==========
#define MOTOR_REVERSE_BLANK_MS     (50U)   // 反转消隐时长（ms），改此宏即可调整

// ========== 反转消隐全局标志位 ==========
// dev_sensor 使用此标志在消隐期间跳过过流检测
extern volatile uint8_t g_u8MotorReverseBlankActive;
```

### dev_motor.c — 状态变量定义

```c
// ========== 反转消隐变量 ==========
static uint8_t s_u8LastArbWasRev = 0;              // 上一次仲裁是否是反转
static NonBlockingDelay_t s_stcReverseBlankTimer;   // 50ms 非阻塞定时器
volatile uint8_t g_u8MotorReverseBlankActive = 0;   // 消隐标志（dev_sensor 读取）
```

### dev_motor.c — 首次进入反转时启动消隐

```c
__weak void Motor_OnArbitrationRev(MotorDevice_t* motor, float duty) {
    (void)motor;
    // 只在刚切换到反转时启动消隐（s_u8LastArbWasRev==0 表示上一次不是反转）
    if (!s_u8LastArbWasRev) {
        nbDelay_Init(&s_stcReverseBlankTimer, MOTOR_REVERSE_BLANK_MS);
        nbDelay_Start(&s_stcReverseBlankTimer);
        g_u8MotorReverseBlankActive = 1;
    }
    s_u8LastArbWasRev = 1;
    // ... 后续 GPIO 控制代码（PHU/PHV）
}
```

### dev_motor.c — 离开反转时立即清除

```c
// Motor_OnArbitrationFwd 和 Motor_OnArbitrationStop 中:
s_u8LastArbWasRev = 0;
g_u8MotorReverseBlankActive = 0;
```

### dev_motor.c — 定时器到期自动清除

```c
// Motor_Update 中，每次主循环都会检查:
if (g_u8MotorReverseBlankActive && nbDelay_IsComplete(&s_stcReverseBlankTimer)) {
    g_u8MotorReverseBlankActive = 0;
}
```

`nbDelay_IsComplete` 基于 `tickTimer_GetCount()`（每 1ms tick 一次），非阻塞，不卡主循环。

### dev_sensor.c — 消隐期间跳过过流检测

```c
// ========== 过流检测统一入口 ==========
static void Sensor_CheckOvercurrent(Sensor_Device_t* pstcDev) {
    if (!pstcDev) return;

    // 反转消隐期间跳过过流检测
    extern volatile uint8_t g_u8MotorReverseBlankActive;
    if (g_u8MotorReverseBlankActive) {
        return;
    }

    // ... 原有过流检测逻辑（SampleCount / TimeWindow 两种模式）
}
```

`extern` 声明在函数内部是合法的 C 写法，编译器知道类型，链接器在 `dev_motor.o` 中找到定义，跨 `.o` 解析。

## TickTimer 依赖

`NonBlockingDelay_t` 的非阻塞延时依赖 `tickTimer_Update()` 每 1ms 被调用一次来推进 tick 计数。消隐定时器的 50ms 到期判断基于此机制。

## 注意事项

1. **消隐期间 ADC 读取和电流计算照常进行**，Modbus 上报的电流值不受影响，只有过流报警判断被跳过。
2. **消隐只在反转方向生效**，正转的过流保护不受影响。
3. **紧急切换立即清除**：如果电机从反转变为停止或正转，消隐标志立即清零，不会延迟影响到新方向的过流保护。
4. **非阻塞**：消隐定时器基于 `TickTimer` 的非阻塞延时，不会卡住主循环。
5. **调整消隐时长**：修改 `dev_motor.h` 中的 `MOTOR_REVERSE_BLANK_MS` 宏即可，无需改动 `.c` 文件。
